# markdown

## Markdown 是什么？

**Markdown** 是一种「轻量级标记语言」，主要用于编写格式化的文本，比如写文档、笔记、README、博客等。
 它的核心思想是：**用简单的符号，让纯文本也能表现出排版效果。**

✅ 优点：

- 语法简单，容易上手
- 文件纯文本格式（.md），体积小，兼容性好
- 可以直接在 GitHub、Notion、VS Code、VuePress 等工具中使用

## 基础语法

### 1. 标题（#）

用 `#` 表示标题层级。`#` 的数量越多，标题层级越小。

```
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
```

效果：就不演示了

### 2. 段落与换行

- 直接敲两次回车就是新段落
- 行尾加两个空格再回车可以**强制换行**

```
这是第一行  
这是第二行（上面两个空格+回车）
```

### 3. 粗体、斜体、删除线

```
**粗体**
*斜体*
~~删除线~~
```

效果：**粗体**、*斜体*、~~删除线~~

### 4. 引用（>）

```
> 这是一个引用
>> 这是嵌套引用
```

效果：

> 这是一个引用
>
> > 这是嵌套引用

### 5. 列表

#### 无序列表（-、*、+ 都可以）

```
- 苹果
- 香蕉
- 橙子
```

效果：

- 苹果
- 香蕉
- 橙子

#### 有序列表

```
1. 第一项
2. 第二项
3. 第三项
```

效果：

1. 第一项
2. 第二项
3. 第三项

### 6. 链接与图片

#### 链接

```
[OpenAI 官网](https://openai.com)
```

效果：[OpenAI 官网](https://openai.com)

#### 图片

```
![替代文字](https://picsum.photos/200)
```

效果：
 ![百度图片i](http://gips3.baidu.com/it/u=1821127123,1149655687&fm=3028&app=3028&f=JPEG&fmt=auto?w=720&h=1280)

### 7. 代码与代码块

#### 行内代码

```
使用 `console.log()` 输出信息
```

效果：使用 `console.log()` 输出信息

#### 代码块

\```语言名
 代码内容
 \```

例如：

```
​```javascript

  console.log("Hello Markdown!");
}
效果：

​```javascript
function sayHi() {
  console.log("Hello Markdown!");
}
```

```

-  学会标题

### 2. 目录（部分平台支持）

写上：

```
[TOC]
```

即可生成自动目录（GitHub 不支持，但一些编辑器如 Typora、VS Code 插件支持）
